# TASKS — задачи агента

Точка входа для агента. Порядок жёсткий.
Найди первую задачу со статусом `[ ]`, выполни ТОЛЬКО её, поставь `[x]`, остановись.

## Инструкция агенту

При старте сессии:

1. Прочитать `BRIEF.md` целиком.
2. Прочитать `RULES.md`.
3. Найти первую задачу со статусом `[ ]` сверху вниз.
4. Назвать вслух номер задачи и её критерии готовности, до того как начать.
5. Выполнить только её.
6. Проверить себя по критериям.
7. Поставить `[x]` и одну строку в заметке: что сделано, что осталось непонятным.
8. Остановиться. Следующую задачу не брать.

Чего не делать:

- Не выполнять несколько задач подряд.
- Не менять порядок задач.
- Не переписывать `BRIEF.md` и `RULES.md`. Их правит только владелец.
- Не додумывать. Если решение неочевидно — остановиться и спросить.
- Не добавлять зависимость молча.

## T-1 — Скелет проекта

Читать: BRIEF.md § 3, § 6, RULES.md

Создать проект: Vite, React, TypeScript в строгом режиме, pnpm.
Поставить Mantine, TanStack Query, fflate.
Настроить ESLint и Prettier. В tsconfig включить `strict`, `noUncheckedIndexedAccess`,
`noImplicitOverride`.
Создать пустую структуру папок по § 6 брифа. Пустые папки не создавать —
только те, в которые сразу что-то ложится.
Провайдеры Mantine и TanStack Query поднять в `app`.

Готово когда:
- `pnpm dev` запускается, страница открывается
- `pnpm lint` и `pnpm typecheck` проходят чисто
- в `package.json` нет лишних зависимостей

Коммит: `chore: bootstrap vite react typescript project`

Заметка: Скелет Vite/React 19/TS strict, провайдеры в app, заглушка страницы; PostCSS-тройка — штатный сетап Mantine для миксинов и брейкпоинтов в T-5. Папки features/entities/shared не создавал.

## T-4 — Сборка ссылок на медиа

Читать: BRIEF.md § 8.1, § 7, § 9 пункт 3

Самая важная задача проекта.

Получить диапазоны корзин из `upstreams` и по ним определять номер корзины
для артикула. Диапазоны НЕ зашивать в код как единственный источник.
Зашитый список допустим только как аварийный запас, если запрос не прошёл,
и это должно быть видно в коде комментарием.
Собрать функции построения ссылок на фотографии и на видео.

Написать тесты на эту функцию: минимум три случая на разные диапазоны
и один на границу диапазона.

Готово когда:
- ссылки собираются из живых данных, а не из зашитого списка
- тесты проходят
- аварийный запас есть и помечен комментарием, зачем он

Коммит: `feat(product): build media urls from live cdn upstreams`
В теле коммита объяснить, почему диапазоны не зашиты.
